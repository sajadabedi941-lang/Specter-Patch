9. LAST-WINS DETERMINATION (STATIC)
--------------------------------------------------------------------------------
Zero Hour loads every *.big from the game folder, then loose files override BIGs.

Observed INI-bearing BIG filename sort (case-insensitive ASCII):
  EnglishZH.big
  INIZH.big
  INIZHZ.big
  PatchZH.big
  _SPEC_ART_ONE.big
  _SPEC_DATA_ONE.big

Underscore-prefixed Specter packs sort after letter-prefixed stock BIGs.
Therefore, for a shared packed path such as Data\INI\CommandSet.ini,
the last-wins copy is the one inside _SPEC_DATA_ONE.big
(418,474 bytes, CRLF-only), not INIZH (144,715) or INIZHZ (145,419).

Same rule for:
  CommandButton.ini, Weapon.ini, Armor.ini, Locomotor.ini,
  Science.ini, PlayerTemplate.ini, Data\English\generals.csf

Launch_Specter.bat contains a comment claiming INIZH.big wins
CommandSet.ini / CommandButton.ini over _SPEC_DATA_ONE.big, and that
INIZHZ.big exists to overlay USA bars after INIZH. That comment is
recorded here as installer text only. Statically, _SPEC_DATA_ONE.big
is the later filename and contains the large Specter cores. This
environment cannot launch Zero Hour to prove engine load order.

Loose-file last-wins:
  Data\INI is empty, so no loose INI override.
  Loose Art\* overrides packed ART for those 73 names only.
  Root NorthKoreaUAVSaetbyol.ini is not a Data\INI loose override.

Inside _SPEC_DATA_ONE.big there are no duplicate packed paths, so
in-pack last-wins == the single packed file for each path.
Some INI files still contain later same-name Object/CommandButton
blocks (raw header count > unique name count). Those in-file last
definitions are the live names inside that file.
