ROOT CAUSE (identified before patching)
======================================================================
GLOBAL_COMMON_CAUSE = YES
GLOBAL_AIRBASE_CONSTRUCTION_ROOT_CAUSE = Player-buildable LargeAirBase / HeavyAirBase objects used Model TheAirPort / HXUSABigAirPort. Those W3Ds exist in SPEC ART but their hierarchy chunks store no pivot data (TheAirPort header claims 101 pivots with an empty hierarchy container; HXUSABigAirPort has no PIVOTS chunk). ExtraPublicBone + W3DModelDraw against a pivot-less hierarchy invalidates the ThingTemplates, so the two dozer aviation buildings cannot be constructed. PR #482 did not introduce this: CommandButton.ini is byte-identical to SPECTER1; CommandSet.ini differs only by the approved Iraq MIC buttons and Iraq Heavy AirBase slot 3.

SECONDARY (faction-specific, also blocking construction):
- GLAInfantryWorker CommandSet = GLAWorkerCommandSet, but only CommandSet GLAWorkerCommandSetg exists.
- Israel StartingUnit0 Israel_VehicleDozer was OBJECT_NOT_PRESENT (file defined only AirF_AmericaVehicleDozer).

AFFECTED_FACTIONS = all playable factions whose builder exposes LargeAirBase and/or HeavyAirBase (USA, China, Russia, Iran, Iraq, Syria, UAE, Saudi, Libya, India, Pakistan, Israel/AirF, Turkey, France, Germany, Italy, Britain, Sweden, Ukraine, NATO, Japan, South Korea, North Korea, Vietnam, South Africa, Egypt Large only). GLA uses stock Arabic airfields (working Arb_Airfield) but the worker CommandSet name was broken.

AFFECTED_BUILDING_TYPES = *LargeAirBase (TheAirPort) and *HeavyAirBase (HXUSABigAirPort)

PR #482 vs SPECTER1 aviation construction: NO unintended global CommandSet/CommandButton construction regression.

REPAIR (minimal, DATA only)
======================================================================
For every *LargeAirBase / *HeavyAirBase object:
- Replace Draw/ExtraPublicBone/Model/Animation with that faction's original working airfield W3D
  (US_AirField, Irq_Airfield, Chi_Airfield, RUS_Airfield, iran_airfield, Isr_Airfield)
- Replace GeometryMajor/Minor/Height with the donor airfield footprint so placement is legal
- Preserve Object name, Side, Prerequisites, BuildCost/Time, KindOf, CommandSet (aircraft slots),
  ParkingPlaceBehavior NumRows/NumCols, production bars

GLA: CommandSet GLAWorkerCommandSet -> GLAWorkerCommandSetg (typo fix only)

Israel: add Object Israel_VehicleDozer (clone of AirF dozer, Side=Israel) and IsraelDozerCommandSet
targeting existing Side=Israel objects. Intended Israel-side aviation building is Israel_Airfield_T
(Irq_Airfield). Israel_LargeAirBase / Israel_HeavyAirBase remain AirF-sided (AmericaAirForceGeneral)
and were model-repaired for AirF.

ART was not rebuilt. TheAirPort.W3D and HXUSABigAirPort.W3D remain in ART unused by construction.

Boss_VehicleDozer / Boss CC objects remain missing (pre-existing; no aviation pair exposed).
No Boss objects were invented.
