The custom airbase system in OLD _SPEC
--------------------------------------
OLD _SPEC contains ZERO LargeAirBase / HeavyAirBase / TheAirPort /
HXUSABigAirPort object definitions.

The working custom aviation building is AdvancedAirBase:

  Mesh     = US_AirField   (internal dependency of the OLD implementation)
  Scale    = 1.60
  Parking  = NumRows 2 x NumCols 8 = 16 pads
  KindOf   includes FS_AIRFIELD
  Heavies  are produced FROM the same 16-pad AdvancedAirBase
           (there is no separate 6-pad / 3x2 heavy building in OLD)

PR #482 had stubbed those objects to comments and added LargeAirBase /
HeavyAirBase (TheAirPort / HXUSABigAirPort) which do not construct.
