============================================================
Root cause
============================================================
  32-bit Wine 9.0 on this cloud host cannot finish Zero Hour engine
  init. The AV is inside stock game.dat while filling a 101x101 dword
  buffer (typical wined3d/GDI surface or init table), after the splash
  movie, before the shell/menu.

  Ruled out by bisect:
  - Tigr objects / Upgrade_RUS_Tier1 / Upgrade.ini (byte-identical
    to capture; crash has no INI line)
  - PR #511 DATA-only edits (same crash without _SPEC_DATA_ONE.big)
  - _SPEC_ART_ONE.big (same crash with ART hidden)
  - INIZHZ.big, CommandSet.ini, CommandButton.ini overlays
  - Faction INI / missing Specter W3D (stock ZH still AVs)
  - BIG last-win of Specter vs INIZH

  Last known "working" wine note (WF_AIRFORCE changelog) also never
  reached playable skirmish (D3D/OLE/no audio). Splash + ReleaseCrashInfo
  is as far as this host gets.
