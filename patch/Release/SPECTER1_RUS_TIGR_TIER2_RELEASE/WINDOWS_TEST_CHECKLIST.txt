Checklist
---------
1. Backup original _SPEC_DATA_ONE.big
   Close generals.exe. In the game folder, copy
   _SPEC_DATA_ONE.big to _SPEC_DATA_ONE.big.bak

2. Copy release files next to generals.exe
   From SPECTER1_RUS_TIGR_TIER2_RELEASE.zip, copy
   _SPEC_DATA_ONE.big into the game folder (replace existing).
   Optional: Get-FileHash .\_SPEC_DATA_ONE.big -Algorithm SHA256
   must match the DATA SHA256 above.
   Or run Install_SpecterPatch.bat and enter the game folder.

3. Launch Zero Hour
   Start generals.exe. Confirm the main menu loads.

4. Open skirmish
   Menu → Skirmish. Confirm the skirmish setup screen opens.

5. Select Russia faction
   Choose Russia and start the match.

6. Test Tigr1 build
   Build Weapon Industry Plant (Industrial Complex).
   Slot 6 = Tigr1 (always available).
   Queue and complete RussiaVehicleTigr1.
   Command Center slot 11 also builds Tigr1.

7. Apply Upgrade_RUS_Tier2
   Confirm Upgrade_RUS_Tier2 still exists (Command_RUS_Tier2).
   On the same plant, slot 5 = Tigr2 research
   (Command_Upgrade_Rus_Tigr2 / Upgrade_Rus_Tigr2).
   Purchase and complete that research. Tigr2 unlocks after it finishes.

8. Test Tigr2 build
   After the upgrade, plant slot 10 = Tigr2 UNIT_BUILD.
   Queue and complete RussiaVehicleTigr2.

Mark each step PASS or FAIL. Restore _SPEC_DATA_ONE.big.bak to revert.
