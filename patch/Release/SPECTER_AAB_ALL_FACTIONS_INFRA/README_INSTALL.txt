SPECTER — Advanced Air Base Infrastructure (All Factions)
=========================================================

Install
-------
1. Backup your current _SPEC_DATA_ONE.big and _SPEC_ART_ONE.big
2. Copy the release BIG files into your Specter / Generals Zero Hour Data folder
3. Launch Specter

Contents
--------
- Separate AdvancedAirBase object for each faction (30)
- Faction art retained (USA Revolution ABAirF2, RUS/Chi/Iran/Isr/Arb/Irq/US airfields)
- Large runway support, repair/refuel, increased pad capacity
- Heavy-aircraft-ready parking/geometry (no heavy aircraft added yet)
- No aircraft INI changes; no B-2/B-52/AWACS
- CommandSet.ini untouched
- USA: Strategy Center construct buttons build America_AdvancedAirBase
