Install
1. Close the game.
2. Go to your Specter / Generals game folder (where the existing SPEC BIGs are).
3. Backup or delete the old:
     _SPEC_DATA_ONE.big
     _SPEC_ART_ONE.big
4. Copy BOTH new BIG files from this zip into that folder.
5. Do not unpack the .big files.
6. Remove temporary ZZZZZZ_* B-2 addon BIGs if present (content is inside these SPECs).
7. Start the game.
