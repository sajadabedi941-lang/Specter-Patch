SPECTER B-2 — DATA + ART BIG PACK (Generals-style)
=================================================

Files:
  ZZZZZZ_SPECTER_B2_DATA.big
  ZZZZZZ_SPECTER_B2_ART.big

These load like Specter SPEC_DATA_ONE.big / SPEC_ART_ONE.big:
  - DATA BIG contains only Data\... (INI, Object, Weapon, CommandButton,
    CommandSet, AudioEvents, FX, OCL, particles, armor, upgrades, audio WAVs)
  - ART BIG contains only Art\... (W3D models, TGA/DDS textures, effect assets)

INSTALL
1. Copy BOTH .big files into your Generals Zero Hour / Specter patch folder
   (same place as _SPEC_DATA_ONE.big and _SPEC_ART_ONE.big).
2. Keep both files. The ZZZZZZ_ prefix makes them load LAST.
3. Do not unpack them. The game reads the packed files inside the BIG archives.
4. Keep your existing Specter / Advanced Air Base patches loaded underneath.
5. Start USA → build America Advanced Air Base → produce B-2.

NOTES
- Gameplay content is unchanged from the completed B-2 port; this release only
  packages it into proper DATA/ART BIG archives.
- Voice AudioEvents reference stock ZH voice stems provided by base English audio.
