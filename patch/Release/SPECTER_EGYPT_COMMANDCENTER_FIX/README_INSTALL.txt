Egypt_CommandCenter FIX — PLAYABLE PACKAGE
==========================================

Contains repaired Egypt_CommandCenter rebuilt from USA CommandCenter
structure (us_commandcenter / US_Command / US_COM_Strb) with Egypt
specials, Side, CommandSet, and balance preserved.

INSTALL
-------
1. Close Generals / Specter.
2. Backup your current _SPEC_DATA_ONE.big and _SPEC_ART_ONE.big.
3. Copy this package's _SPEC_DATA_ONE.big and _SPEC_ART_ONE.big into
   your Specter main game folder (same place as EnglishZH.big / AudioZH.big).
4. Launch Specter and select Egypt.

Balance (cost/time/HP/CommandSet) unchanged.
