SPECTER EGYPT PLAYABLE FULL PATCH
=================================

Full updated Specter patch overlay including playable Egypt plus the
existing working factions:
  Iran, Israel, Iraq, Russia, China, USA, North Korea, Egypt

This ZIP contains the COMPLETE patch (Data + Art), not a delta.

--------
  Patch\Data\     Full INI / English / economy overlay
  Patch\Art\      Art overlays
  Patch\SYNC_MANIFEST.sha256
  README_INSTALL.txt
  VALIDATION_REPORT.txt

INSTALL
-------
1. Close Generals Zero Hour / Specter completely.
2. Copy / merge:
     Patch\Data  →  <GameRoot>\Data
     Patch\Art   →  <GameRoot>\Art
3. Do NOT replace Data.zip, vendor *.big, or _SPEC_* archives unless
   your install method already uses Spec BIGs as the primary load path.
4. Launch Specter and select Egypt in Skirmish.

UNINSTALL
---------
Remove the overlay files you copied, or restore from your own backup.
