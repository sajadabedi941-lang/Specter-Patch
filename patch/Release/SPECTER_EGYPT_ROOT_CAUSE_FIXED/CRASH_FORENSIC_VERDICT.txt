EXACT CRASH FORENSICS — FINAL VERDICT
=====================================

A) Exact crash reason
---------------------
Game initializes Object Egypt_CommandCenter from:

  Data\INI\Object\Specter\Egyptian Armed Forces\Buildings\Egypt_CommandCenter.ini

inside vendor _SPEC_DATA_ONE.big (SHA of that INI =
1b559b9e0d4eb1400e76934196eb71205c1ff21317e610d717c1da1dc7870b61).

That INI is an Iraq-donor clone of Egypt's Command Center. During object bind,
it wires Egypt's CommandCenter to Iraq portraits/models/gunship/OCLs:

  SelectPortrait/ButtonImage = irq_comndcntr
  Model                      = Irq_Command
  GunshipTemplateName        = Iraq_Adnan1
  OCL                        = SUPERWEAPON_IraqiSFInsertion
  OCL                        = SUPERWEAPON_IraqiParadrop
  OCL/UpgradeOCL             = SUPERWEAPON_IraqiCruiseStrike1/2/3
  OCL                        = SUPERWEAPON_IraqReconnaissance

Uncaught Exception is raised while loading that file.

Install root cause:
  Many "fix" packages leave the broken vendor _SPEC_DATA_ONE.big in place
  (or reinstall a playable package that still embeds sha 1b559b9e…).
  If that BIG is what the game loads for Data, Egypt_CommandCenter crashes.
