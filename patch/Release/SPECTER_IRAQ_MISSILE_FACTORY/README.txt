SPECTER — Iraq Missile Factory (IQMISS) Release
================================================

This package imports the Donor Iraqi Missile Factory ART and adds it as a
separate Iraq building. It replaces only the Iraqi construction-vehicle
Clear Mines slot with Missile Factory.

Object:        Iraq_MissileFactory
CommandButton: Command_ConstructIraq_MissileFactory
CommandSet:    Iraq_VT72BCommandSet  (slot 14 only)
Factory bar:   Iraq_MissileFactoryCommandSet

Existing Iraq War Factory (Iraq_WarFactory / Iraq_WarFactory_T / Irq_WarFactory.W3D)
is unchanged.

This environment cannot launch Zero Hour. Validation is static archive/INI
checks only. Do not treat this as an in-game runtime proof.
