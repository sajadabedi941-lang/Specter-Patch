# DONOR ART — Complete Fighter Aircraft Inventory

**READ-ONLY AUDIT** — No DATA/ART/BIG modifications.

**Source:** `/tmp/donor_art_extract/Art/w3d` (full extract of `DONOR_Art.part001.rar` … `part069.rar`)

**Scope:** Fighter / multirole / interceptor / strike-fighter / fighter-bomber / carrier fighter only.
W3D variants (`_D`, `_E`, `_K`, LOD, wreck, skins) are grouped into one aircraft family.

**Note on LSF* models:** Many donor fighters use the `LSF*` (display/unit pack) naming. These are real aircraft W3Ds in DONOR ART.

**Classic Specter names** (`US_F16*`, `Irq_Mig29*`, `Egy_Rafale*`, etc.) are **NOT** present in DONOR_Art; those live in SPEC ART. This inventory is DONOR_Art only.
