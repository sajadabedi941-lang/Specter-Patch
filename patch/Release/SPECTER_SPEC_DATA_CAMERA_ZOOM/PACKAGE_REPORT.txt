Why the extra file is required
------------------------------
This game.dat keeps the first Data\INI\GameData.ini. INIZH.big is mounted
before _SPEC_DATA_ONE.big, so the GameData.ini inside this archive is not the
opened file. GameData init does not scan Data\INI\GameData\. It does scan
Data\INI\Object for *.ini in local files and archives, after GameData.ini,
with overwrite. The added object INI is the path that can change the live value.
