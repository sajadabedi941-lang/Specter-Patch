Install
=======
1. Backup current _SPEC_DATA_ONE.big / _SPEC_ART_ONE.big
2. Copy this package BIGs into the Specter / ZH Data folder
3. Start USA skirmish
4. Build AdvancedAirBase from Strategy Center / dozer path
5. Confirm slots 1-8: B-2, B-1B, B-52, EA-18G, E-3, C-17, KC-135, AC-130
