INSTALL
=======
1) Extract ZIP
2) Copy _SPEC_DATA_ONE.big and _SPEC_ART_ONE.big into your Specter Generals game root
   (same folder as generals.exe / Zero Hour)
3) Launch Specter
4) USA Airfield -> B-2 Spirit button (slot 5)
5) Build AmericaJetB2, attack, return to base (AutoReloadsClip = RETURN_TO_BASE)

Do NOT modify USA Airfield Object/W3D.
Do NOT use AdvancedAirBase.
