SPECTER_USA_BUILD_FIX_FINAL
===========================
Restores USA dozer construction menu after String Manager fix.

Install:
1. Backup existing _SPEC_DATA_ONE.big / _SPEC_ART_ONE.big
2. Copy this pack's BIG files into the Specter Data folder
3. Start a USA match, select a dozer, confirm build icons appear

Keeps: B-2/B-1B/B-52/E-3/C-17/KC-135/AC-130, USA helicopters, AdvancedAirBase
Does not: edit strings, remove aircraft, add factions, touch CommandSet.ini
