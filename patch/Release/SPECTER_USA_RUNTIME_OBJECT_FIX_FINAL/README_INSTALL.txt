Install
=======
1. Backup your current _SPEC_DATA_ONE.big / _SPEC_ART_ONE.big
2. Copy this package's BIGs into the Specter / Generals Zero Hour Data folder
   (same locations you used for SPECTER_USA_AC130_PARSE_FINAL)
3. Do not mix older USA AAB DATA BIGs on top of this package
4. Launch USA skirmish and verify AAB aircraft production
