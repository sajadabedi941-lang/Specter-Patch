SPECTER USA STRATEGY CENTER BUILD FIX
=====================================

ROOT CAUSE
----------
USA Dozer slot 2 uses Command_ConstructAmericaStrategyCenter_T which targeted
AmericaStrategyCenter_T. That object Prerequisites lock the button:

  patch/.../Buildings/StrategyCenter.ini
    line 44: Object = AmericaWarFactory_T
    line 45: Object = AmericaRadarStation   <--- exact line that greys the button

AmericaRadarStation also requires Airfield (Buildings/AN_FPS117.ini line 28),
so the Strategy Center button stayed disabled/grey until Airfield+Radar+WarFactory.

Not caused by RequiredScience / Rank / RequiredUpgrade on the CommandButton.
Not linked to America_AdvancedAirBase after SC building restore.

FIX
---
Added last-wins overlay:
  Data\INI\ZZZZZZZZ_ZZZZZZZZ_ZZZZZZZZ_ZZ_USA_SC_BUILD_FIX.ini

- Command_ConstructAmericaStrategyCenter   -> AmericaStrategyCenter
- Command_ConstructAmericaStrategyCenter_T -> AmericaStrategyCenter
- AmericaStrategyCenter Prerequisites restored to original Specter (commented)
- CommandSet = AmericaStrategyCenterCommandSet
- No RequiredScience / RequiredUpgrade / Rank / AdvancedAirBase

NOT MODIFIED
------------
- USA Airfield / AmericaAirfield_T
- USA_FINAL14_AIRFIELD_COMMANDSET
- aircraft roster / B-2 / B-52H / B-21
- CommandSet.ini
- ART (unchanged from FINAL14 pack)
