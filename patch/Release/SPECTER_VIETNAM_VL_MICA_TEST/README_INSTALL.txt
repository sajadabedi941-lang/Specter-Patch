SPECTER Vietnam VL MICA — Command Center test pack
==================================================

Adds New Donor VL MICA (Object FranceVlmica) to Vietnam only.
Patriot / ABM / Taiwan originals / other AD are not modified.

Install
-------
1. Extract this ZIP into SPECTER FINAL (the folder with generals.exe).
2. Replace:
     _SPEC_DATA_ONE.big
     _SPEC_ART_TWO.big
3. If Data\INI\CommandSet_Vietnam.ini is in the ZIP, it updates the
   loose Vietnam CommandSet (slot 3 = VL MICA) without removing other
   buttons. The packed CommandSet.ini already has the live CC button.

Build
-----
Vietnam Command Center -> VL MICA (New Donor LSFziyuan launcher).
Deploy before it fires. Cost 5000 / 15s (New Donor values).

In-game test
------------
Not run on this machine. Archive/hash/INI checks only.
