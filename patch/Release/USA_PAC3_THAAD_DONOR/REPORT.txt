v7 Deploy-button lock after AA/ABM (proven, then minimal DATA fix)
-----------------------------------------------------------------
Symptom: unit builds, AA or ABM can be selected, then Deploy is grey.

Not the CommandButton. Command_ADSCombatMode is FIRE_WEAPON
SECONDARY, Command_ADS_ABM_CombatMode is FIRE_WEAPON TERTIARY. No
NEED_UPGRADE / science Options. Same buttons US_THAAD uses.

Not a missing CommandSet. S400ECommandSet has the mode upgrades.
CommandSetUpgrade then switches to S400ECommandSet_AA (slot 6 =
Command_ADSCombatMode) or _ABM (slot 6 = Command_ADS_ABM_CombatMode).
That is why Deploy appears after the mode click.

Not Prerequisites / UnitSpecificSounds. Construct Prerequisites stay
empty from v6. Sounds match THAAD. New Donor has no FIRE_WEAPON
Deploy button (GLAVehicleRocketBuggyCommandSet).

The lock was Object USAPAC3 DeployStyle turret ownership:
  ControlledWeaponSlots = PRIMARY SECONDARY TERTIARY
  InitiallyDisabled     = Yes
  TurretsFunctionOnlyWhenDeployed = Yes
SECONDARY/TERTIARY are US_PAC3_DeployCue, the FIRE_WEAPON payload.
A disabled turret that owns those slots makes the slots unusable
while packed. Deploy is what would enable the turret. Chicken-and-egg.

Working comparison — packed Object US_THAAD (US_M1120.ini, not edited):
  Same Command_ADSCombatMode / S400ECommandSet_AA path
  Weapon SECONDARY S400R_Deploy, TERTIARY S400R_Deploy_ABM
  DeployStyleAIUpdate with TurretsFunctionOnlyWhenDeployed = Yes
  but NO Turret block, so the Deploy weapon is not turret-gated
  Deploy is clickable (then suicide-unpacks; that is THAAD, not PAC-3)

v3/v4 PAC-3 also had a clickable Deploy (then exploded) because they
used S400R_Deploy with no turret wrapping SECONDARY.

New Donor put combat SECONDARY on that turret. SPECTER cannot: the
loose Deploy buttons are FIRE_WEAPON SECONDARY/TERTIARY.

v7 change: ControlledWeaponSlots = PRIMARY only. Combat stays
turret-gated (no packed fire). DeployCue is a body weapon like THAAD.
LRSAM / ABM templates, Draw, ART, and v6 Prerequisites are unchanged.

0. What this pack changes
-------------------------
Previous packs (v1–v4) cloned THAAD’s suicide/OCL swap onto the PAC-3
truck. That is the wrong architecture. v5 restores New Donor’s single
object DeployStyle unpack/pack on Object USAPAC3, then attaches THAAD
intercept weapons to that same object. No CombatMode, PackMode, or
FCS object is created. S400R_Deploy / S400R_Pack are not used.

  Command_ConstructUSAPAC3  Object = USAPAC3
  AmericaCommandCenterCommandSet slot 6 = Command_ConstructUSAPAC3
Loose Data\INI is not edited. Object US_THAAD (US_M1120.ini) is
byte-identical to v4/ss1.

6. Join map (no suicide)
------------------------
  1. Build USAPAC3 → packed Car, CommandSet S400ECommandSet
     (AA / ABM / MTS buttons). PRIMARY is LRSAM but turrets are
     disabled until deployed.
  2. AA → CommandSetUpgrade S400ECommandSet_AA
     ABM → CommandSetUpgrade S400ECommandSet_ABM
           + WeaponSetUpgrade PLAYER_UPGRADE → US_PAC3Missile_ABM
     MTS → CommandSetUpgrade S400ECommandSet_AA (Deploy button).
           ZH WeaponSetUpgrade only sets WEAPONSET_PLAYER_UPGRADE
           (one bit), so MTS cannot have a third exclusive weapon
           set. MTS keeps the AA LRSAM set.
  3. Deploy button FIRE_WEAPON SECONDARY or TERTIARY.
     Both slots are Weapon US_PAC3_DeployCue:
       PrimaryDamage 0, DeathType NORMAL, no SELF SUICIDE, no FireOCL.
     DeployStyleAIUpdate unpacks first (Car jack clip), then the
     dummy fires. The truck stays Object USAPAC3.
  4. After DEPLOYED, model is UsaPac3F (launcher-up rest pose).
     TurretsFunctionOnlyWhenDeployed allows PRIMARY. AutoAcquire
     starts THAAD intercept (AA or ABM by weaponset).
  5. Missiles are US_PAC3_AA_OBJECT / US_PAC3_ABM_OBJECT (pac3mis_m).
  6. Pack: native DeployStyle pack on a move order (Donor). Combat
     turrets disable while packing/packed.
     Command_FireControlPack is FIRE_WEAPON SECONDARY and the engine
     always unpacks before a FIRE_WEAPON shot, so that button cannot
     pack a DeployStyle unit. This object is therefore not given
     S400ECommandSet_Deployed. Pack is Move. That is an engine limit
     of the uneditable loose buttons, not a missing INI line.
