Crash fix (v2) — why the first pack still crashed
-------------------------------------------------
W3DTruckDraw on Object USAPAC3 (KindOf PRELOAD) preloads every Model
and Animation named in the Draw module at game start / spawn.
UsaPac3Car.UsaPac3Car is a 101-frame clip with only BIT_CHANNEL tracks
(not a THAAD-style deploy transform). The previous USAPAC3 already
crashed after the empty UsaPac3F Animation= was stripped; the remaining
preload was this Car clip plus W3DTruckDraw tire setup. v1 also added a
second W3DTruckDraw (UsaPac3Car_w) with ConditionState=NONE and no
DefaultConditionState.

v2 changes (TEL objects only; US_THAAD untouched):
  Draw = W3DModelDraw, model-only Car / Car_d / deployed F / F_d
  no Animation= lines
  no second tire Draw
  PRELOAD removed from USAPAC3 / CombatMode / PackMode KindOf
  ART: delete 0x200 chunks from UsaPac3Car, UsaPac3Car_d, pac3mis_m,
       UsaPac3Car_w

Fire chain, slot 6, and loose Data\INI are unchanged. Still not an
in-game test.
