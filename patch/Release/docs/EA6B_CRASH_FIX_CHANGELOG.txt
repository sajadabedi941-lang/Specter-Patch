was present in this environment. This environment cannot launch Zero Hour.

ROOT CAUSE
USA constructs AmericaJetF18Prowler from America_LargeAirBaseCommandSet slot 9.
That object used GenericMultiRoleFighter_AG_CommandSet, which binds
Command_RadioWaveDisabler (SuperweaponRadioWaveDisabler) and Command_GMRF_AAM
(SpecialAbility_AAMode). Working USA jets on the same airfield (F-35C) implement
OCLSpecialPower SuperweaponRadioWaveDisabler. The Prowler did not.
Command-bar construction at produce/spawn is a null-deref CTD.

Second init hazard: CountermeasuresBehavior FlareBoneBaseName=Flare, but
EA6.W3D has no Flare pivot (EMP_V / EMP_B / ENGINE / WINGTIP / BOMB exist).
