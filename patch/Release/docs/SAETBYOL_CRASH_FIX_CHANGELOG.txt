The previous Saetbyol object was cloned from FranceAircraftE3 with a broken
Python regex. VisionRange/ShroudClearingRange replacements used \\11100 and
\\11200, which Python treated as octal escapes producing garbage tokens I00
and J00. The draw also kept E3 ENGINE01-04 ParticleSysBones and an invented
AVReaper.AVReaper animation on the Dozor-600 / AVReaper model (which only
has Wingtip01/02 and CHASSIS).
