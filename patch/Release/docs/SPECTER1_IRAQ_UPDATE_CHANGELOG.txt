Iraq ground / other player units
--------------------------------
Once the normal production building exists, Iraq player units are no longer
hidden behind Radar / MIC / purchased sciences / rank sciences / research
objects / WarFactory-MIC tier CommandSetUpgrade.

  * WarFactory starts on Iraq_WarFactoryCommandSet_T3 (full T3 roster).
    Tier CommandSetUpgrade modules now all point at T3 so buying tiers
    cannot shrink the bar.

  * MIC starting CommandSet now includes Karrar-2, B340, Fahad-3.
    MIC building prereq accepts the live dozer airfields
    Iraq_LargeAirBase and Iraq_HeavyAirBase in addition to the old
    Iraq_Airfield_T name.

  * Object-level production gates removed from Iraq tanks / IFVs /
    launchers / AD vehicles / drones / barracks infantry / Abbas building.
    Building-chain requirements kept (Supply Center, Power Plant, MIC's
    Radar+Airfield+WarFactory requirement).
