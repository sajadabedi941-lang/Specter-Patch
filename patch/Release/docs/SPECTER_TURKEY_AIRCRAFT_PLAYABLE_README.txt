INSTALL
-------
1. Close Generals / Specter.
2. Unzip this package.
3. Run Install_SpecterPatch.bat
4. Enter your Specter GameRoot path when prompted.
5. Wait for: INSTALLATION COMPLETED SUCCESSFULLY
6. Launch Specter.

The installer backs up existing BIG files, then replaces them.
