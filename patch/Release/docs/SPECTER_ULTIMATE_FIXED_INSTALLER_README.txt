HOW TO INSTALL
--------------
1. Close Specter / Generals Zero Hour.
2. Open your game folder (the folder that contains generals.exe).
3. Extract this ZIP into that folder so you get:

     <GameFolder>\SPECTER_ULTIMATE_FIXED_INSTALLER\
         Install_SpecterPatch.bat
         Launch_Specter.bat
         _SPEC_DATA_ONE.big
         _SPEC_ART_ONE.big
         README.txt

4. Open SPECTER_ULTIMATE_FIXED_INSTALLER
5. Double-click Install_SpecterPatch.bat
6. A black CMD window will open and stay open.
7. Wait until you see:

     SPECTER PATCH INSTALLATION COMPLETED SUCCESSFULLY

8. Press any key to close the installer.
9. Start the game with Launch_Specter.bat

WHAT IT DOES
------------
  - Finds generals.exe in this folder or the parent game folder
  - Backs up old BIG files into Backup_SpecterPatch
  - Copies the two new BIG files into the game folder
  - Does not use the internet, Python, or any EXE installer
