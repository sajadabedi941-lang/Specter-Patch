INSTALL
-------
1. Close Generals / Specter.
2. Copy ALL files from this ZIP directly into your
   Command and Conquer Generals Zero Hour folder
   (the folder that already contains generals.exe).
3. Double-click Install_SpecterPatch.bat
4. Wait for: Installation completed successfully
5. Start the game with Launch_Specter.bat

NOTES
-----
  - This installer must sit next to generals.exe
  - Old BIG files are saved into Backup_Specter_Date
  - Only the two BIG files are used for the patch
