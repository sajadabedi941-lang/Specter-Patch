Installer behavior
------------------
  1. Auto-detect GameRoot (installer folder, parents, saved path, common paths)
     or FolderBrowserDialog / typed path fallback
  2. Backup existing _SPEC_DATA_ONE.big / _SPEC_ART_ONE.big
  3. Copy new BIGs into GameRoot
  4. Confirm INSTALLATION COMPLETED SUCCESSFULLY (+ MessageBox)
  5. Desktop shortcut: "Specter Ultimate Expansion"
  6. Optional launch of generals.exe
