SPECTER ULTIMATE EXPANSION — LOOSE FILES PATCH
==============================================

Playable patch in normal folders. NO BIG archives. NO installer.

CONTENTS
--------
  Data/          Full Specter Ultimate Expansion data (INI, objects, weapons, command sets, ...)
  Art/           Full art (W3D models, textures, terrain)
  North Korea/   Extra archive paths preserved from Specter DATA BIG (keep beside Data/)
  README.txt

This is the same content as the Ultimate Expansion playable BIGs,
extracted to loose files for direct copy into the game directory.

INSTALL
-------
1. Close Command & Conquer Generals Zero Hour / Specter.
2. Open your game folder (the folder that contains generals.exe).
3. Copy the folders from this ZIP into that game folder:
     Data
     Art
     North Korea
   If Windows asks to merge/replace folders, choose Yes / Merge.
4. Start Specter / generals.exe.

Do NOT use _SPEC_DATA_ONE.big / _SPEC_ART_ONE.big from this package
(there are none). This patch is loose-file only.

MULTIPLAYER
-----------
Every player must use the same loose-file patch contents.
Mismatching Data/Art between players can cause desync.

INCLUDED CONTENT
----------------
  Turkey aircraft repairs
  UAE / Japan MQ-9
  MilitaryHQ fixes
  Multi-unit repairs
  Air Force Expansion aircraft
  Seven-country drones
  Prior Ultimate Expansion merged playable content

NOTES
-----
  - Folder layout matches Zero Hour / Specter (Data\INI\..., Art\W3D\..., Art\Textures\...)
  - No installer EXE or BAT is required
  - Keep a backup of your original game Data/Art if you already had custom loose files
