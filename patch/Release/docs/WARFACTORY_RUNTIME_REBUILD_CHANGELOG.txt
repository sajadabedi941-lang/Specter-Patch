SPECTER WAR FACTORY RUNTIME REBUILD
===================================

Previous ZZZZ last-wins files did not change the in-game War Factory
because they never edited the winning CommandSet.ini definition.

starting dozer/VT72B to the War Factory object, then overwrites that
live CommandSet inside packed CommandSet.ini (Pakistan also in
CommandSet_Pakistan.ini).

Protected countries are unchanged.
