SPECTER — بازگرداندن overlay ضدبالستیک پس از regression نسخه v4
==============================================================

نسخه AUM Spawn v4 در آزمایش واقعی بازی HQ-9 و S-400 را خراب کرد.
این بسته آن last-winها را برمی‌دارد. شلیک داخل بازی هنوز دوباره تأیید نشده است.

آخرین وضعیت تأییدشده توسط کاربر
--------------------------------
بدون این overlay (یا قبل از v4): HQ-9 و S-400 به موشک بالستیک شلیک می‌کردند.
S-500، THAAD، Arrow و S-300 شلیک نمی‌کردند.
این بسته چهار سامانه را «درست» نمی‌کند.

فایل overlay
------------
  0_SPECTER_ABMDedicatedRadar.big
  اندازه: 1352 بایت
  SHA-256:
    9d41c1b74da0454b27ffb6d68e8741472b281633f354898713af8b70ea2982b5

نصب / جایگزینی v4
-----------------
1. بازی را ببندید.
2. فایل v4 به‌نام 0_SPECTER_ABMDedicatedRadar.big را کنار generals.exe
   با فایل همین بسته جایگزین کنید (همان نام).
3. داخل Data\ یا Art\ نگذارید. پیشوند 0_ را عوض نکنید.
4. _SPEC_DATA_ONE.big و _SPEC_ART_*.big را جایگزین نکنید.

حذف کامل overlay
----------------
اگر می‌خواهید هیچ فایل ABMDedicatedRadar نباشد، همین BIG را از پوشهٔ
generals.exe حذف کنید. رفتار HQ-9/S-400 باید همان SPEC باشد.

این فایل چه کاری نمی‌کند
------------------------
هیچ Object/OCL/Weapon موجود در SPEC را last-win نمی‌کند.
FCS سامانهٔ S-400 را روی سامانه‌های دیگر کپی نمی‌کند.
آمار سلاح، A–J، پدافند کوتاه‌برد و ART را عوض نمی‌کند.
