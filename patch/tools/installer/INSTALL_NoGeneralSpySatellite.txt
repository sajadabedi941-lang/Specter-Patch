SPECTER — remove the general Spy Satellite button
نصب حذف دکمهٔ عمومی Spy Satellite

Download these files into ONE folder. Do not rename them.

- _SPEC_DATA_ONE.big
- _SPEC_ART_ONE.big
- 0_SPECTER_NoGeneralSpySatellite.big
- Launch_Specter.bat
- Install_SpecterPatch.bat
- INSTALL_NoGeneralSpySatellite.txt

Run Install_SpecterPatch.bat once, or Launch_Specter.bat every time you play.
Both copy the three BIG files into the folder that contains generals.exe.
Leave them beside generals.exe. Do not put them inside Data or Art.

The game keeps the first BIG that contains Data\INI\CommandSet.ini.
0_SPECTER_NoGeneralSpySatellite.big is loaded before _SPEC_DATA_ONE.big and INIZH.big.
That is why the name starts with 0_. Renaming it to zz_ makes the fix stop working.

Zero Hour was not launched while this package was built.
